# Voicebank Central（ボイスバンク・セントラル）

**主要な日本語ボイスバンク IP ホルダーのインタラクティブなネットワークマップ**

Vocaloid / UTAU / Synthesizer V 関連企業とその代表的なキャラクターを、ダイナミックなズーム可能なインターフェースで探索できます。

---

## ライブデモ

最新のブラウザ（Chrome、Firefox、Safari、Edge）で `index.html` を開くだけで動作します。  
ビルド手順は不要です。純粋な HTML / CSS / バニラ JavaScript で構成されています。

---

## 主な機能

- **ギャラクシースタイルのナビゲーション** — 企業ハブをクリックするとズームインし、キャラクター一覧が展開されます
- **キャラクターポートレート** — キャラクターノードをクリックするとフルサイズのイラストがモーダルで表示されます
- **動的テーマ** — 背景グラデーションと浮遊パーティクルが選択した企業のカラーに合わせて変化します
- **回路基板風のデザイン** — 走る光のパケットを持つ微細な PCB 風のトレースアニメーション
- **完全レスポンシブ** — スマートフォン（縦・横）とデスクトップ向けにタッチターゲットとレイアウトを最適化
- **アクセシビリティ対応** — セマンティック HTML、適切な ARIA 属性、キーボード操作（Escape でモーダルを閉じる）、フォーカススタイル
