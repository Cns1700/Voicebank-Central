# Voicebank Central（ボイスバンク・セントラル）

**主要な日本語ボイスバンク IP ホルダーのインタラクティブなネットワークマップ**

Vocaloid / UTAU / Synthesizer V 関連企業とその代表的なキャラクターを、ズーム・パン可能なダイナミックなインターフェースで探索できます。アプリとしてもインストール可能です。

**ライブサイト:** [https://cns1700.github.io/Voicebank-Central/](https://cns1700.github.io/Voicebank-Central/)

---

## 主な機能

- **ギャラクシースタイルのナビゲーション** — 企業ハブ（または下部ドック）をクリックするとズームインし、キャラクター一覧が展開されます
- **自由なパン＆ドラッグ** — 背景をドラッグしてマップを自由に探索できます
- **周回するキャラクターノード** — 展開されたキャラクターが企業ハブの周りをゆっくり周回します（スムーズな CSS アニメーション）
- **光る接続ライン** — 企業展開時にハブから各キャラクターへラインが描画されます
- **キャラクターポートレート** — ノードをクリックするとフルサイズのイラストがモーダルで表示されます
- **動的テーマ** — 背景グラデーション・回路の光・浮遊パーティクルが企業カラーに合わせて変化します
- **回路基板風のデザイン** — 走る光のパケットを持つ PCB 風トレースアニメーション
- **PWA インストール対応** — PC / スマホにインストール可能（スタンドアロン表示、オフライン用シェルキャッシュ）
- **最適化された WebP 画像** — 高速読み込みと、キャラクターごとの顔フレーミング調整
- **完全レスポンシブ** — スマートフォン（縦・横）とデスクトップ向けにタッチターゲットとレイアウトを最適化
- **アクセシビリティ対応** — セマンティック HTML、ARIA、ネイティブ `<dialog>`、キーボード操作（Escape でモーダルを閉じる）

## クイックスタート

最新のブラウザで `index.html` を開くか、上記のライブ URL にアクセスしてください。  
ビルド手順は不要です（HTML / CSS / バニラ JavaScript）。

### アプリとしてインストール（PWA）

1. Chrome / Edge / Android Chrome でサイトを開きます。
2. アドレスバーの「インストール」、またはメニューの「ホーム画面に追加 / アプリをインストール」を選びます。
3. スタンドアロンウィンドウで起動し、初回訪問後はコア部分をオフラインでも利用できます。
